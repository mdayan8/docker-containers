# Contributing

Keep this repository focused on the `docker-containers` skill.

## Good contributions

- clearer Dockerfile or Compose guidance
- better failure-mode examples
- narrower, more reliable trigger wording
- compatibility notes for a supported agent path

## Avoid

- unrelated platform advice
- generic AI boilerplate
- large scripts unless they solve a repeated problem
- expanding into Kubernetes or cloud deployment unless the skill actually needs it

## Editing rule

Make changes small, readable, and easy to review.
